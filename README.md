## 🌟 Featured Projects

### 🛰️ GMRT RF Antenna Control System
Real-time RF signal conditioning controller built during my research internship at **NCRA-TIFR**, managing **30 antennas and 60 channels** on the Giant Metrewave Radio Telescope.
- Flask web app interfacing with a **LabJack T7-Pro DAQ** over a 14-pin digital bus protocol
- LAN-based device auto-discovery and live hardware status polling
- **Tech:** `Flask` `Python` `LabJack LJM` `concurrent.futures`

### 🩺 MediSense — Multi-Organ Disease Criticality Prediction
An ML system predicting disease criticality across **lungs, kidney, heart, and liver**.
- Benchmarked **9 supervised ML algorithms + 3 ensemble strategies**, reaching up to **99.4% accuracy**
- **Published at ICRTSET-2026** (ISBN 978-81-998271-6-5)
- **Tech:** `Python` `Scikit-learn` `Pandas`

### 🎬 Movie Recommender System
An NLP-based recommendation engine that suggests movies based on content similarity.
- **Tech:** `Python` `NLP` `Scikit-learn`
